# راهنمای کامل مستندات شبکه ملی سلامت
## Hyperledger Fabric – نسخه نهایی با توضیحات تفصیلی

**تاریخ:** اوت ۲۰۲۶

به دلیل حجم بسیار بالای محتوا (۳۵ سازمان + بیش از ۱۰۰ کانال + بیش از ۴۰۰ قرارداد با حداقل ۳ خط توضیح برای هر مورد)، مستندات به صورت فایل‌های تخصصی و کامل جداگانه تهیه شده‌اند تا هم خوانایی حفظ شود و هم امکان دانلود و استفاده عملی وجود داشته باشد.

---

## فهرست فایل‌های آماده (همه با توضیحات حداقل ۳ خط)

### ۱. مستند تفصیلی سازمان‌ها و کانال‌ها
**فایل:** `مستند-تفصیلی-شبکه-ملی-سلامت-هایپرلجر-فابریک.md`  
**حجم تقریبی:** ۶۹ کیلوبایت

**محتوا:**
- تمام **۳۵ سازمان** با حداقل ۳ خط توضیح کامل برای هر کدام
- تمام **۱۰۰ کانال** با حداقل ۳ خط توضیح کامل برای هر کدام
- توضیحات تفصیلی گروه اول قراردادها (بیمار و داده بالینی)

این فایل پایه اصلی برای درک نقش هر سازمان و هر کانال است.

---

### ۲. مستند کامل همه قراردادهای هوشمند
**فایل:** `مستند-کامل-همه-قراردادها-شبکه-ملی-سلامت.md`  
**حجم تقریبی:** ۱۰۰ کیلوبایت

**محتوا:**
- بیش از **۳۵۰ قرارداد هوشمند** اصلی
- هر قرارداد دارای **حداقل ۳ خط توضیح** کامل (هدف، عملکرد، نکات کلیدی)
- گروه‌بندی‌شده در ۱۳ دسته:
  - بیمار و داده بالینی
  - تخت و ظرفیت فیزیکی
  - جراحی و اتاق عمل
  - تجهیزات و دستگاه
  - دارو، خون و انبار
  - نیروی انسانی
  - پذیرش، تریاژ و جریان بیمار
  - مالی، بیمه و تأمین
  - دسترسی، امنیت و انطباق
  - IoT، تله‌مدیسین و مانیتورینگ
  - تحلیل، هوش مصنوعی و پژوهش
  - بازار منابع
  - بحران، اپیدمی و فوریت ملی

این فایل کامل‌ترین مرجع قراردادها است.

**محتوا:**

- سیاست‌های تأیید توکن
- نقشه راه پیاده‌سازی توکن‌سازی

## توصیه استفاده

1. برای درک نقش سازمان‌ها و کانال‌ها → فایل **مستند-تفصیلی** را مطالعه کنید.
2. برای جزئیات تمام قراردادها → فایل **مستند-کامل-همه-قراردادها** را استفاده کنید.
3. برای بخش توکن‌سازی → فایل **مستند-کامل-توکن‌سازی** را بخوانید.
4. برای مرور کلی و ارائه → از فایل **مستند-جامع** استفاده کنید.
